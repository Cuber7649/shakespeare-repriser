# Text Repriser Collection — Design & UX Improvements

## 1. Declutter the Initial State
- [x] **Hide or collapse empty action bars:** Hide the card action buttons (*Make Card, Copy, Save, Compare, Copy Link*) or collapse them into a single subtle toolbar until a transformation runs.
- [x] **Condense card actions:** Replace the 2x2 + 1 button grid on generated cards with a single horizontal row of icon-only buttons with tooltips to save vertical space.
- [x] **Progressive disclosure for settings:** Collapse **Transformation Settings** (Seed, Stage directions, Sentence inversion) behind an *"Advanced Settings"* toggle so the main CTA buttons sit closer to the input box.

## 2. Fix Color Contrast & Readability
- [x] **Boost top navigation contrast:** Change the active navigation tab (*All Styles*) from dark text on a brown background to a high-contrast cream pill with dark ink text.
- [x] **Darken muted labels:** Darken secondary text (*"0 characters inscribed"*, *"Optional; the same seed replays a run"*, and *"Open page"* links) by 20–30% to meet WCAG AA accessibility standards.

## 3. Tighten Vertical Spacing & Above-the-Fold Focus
- [x] **Reduce header padding:** Trim top and bottom hero padding around the main title by ~40% so users can see the top half of the Shakespeare and Pirate output cards without scrolling.
- [x] **Streamline the Saved Quotes section:** Style the raw browser file input (*Choose file* / *No file chosen*) into a themed button matching *Export* and *Clear all*, or hide the Saved Quotes drawer until the first quote is saved.

## 4. Micro-UX Polish
- [ ] **Add quick-sample pills:** Place 2–3 clickable prompt chips next to *"Surprise Me!"* (e.g., *"Tech layoff email"*, *"Breakup text"*, *"Grocery list"*) so first-time visitors can test the tool in one click.
